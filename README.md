# CareWatch-AI

## AI-Powered Hospital Readmission Prediction and Decision Support System

### MSc Data Science Project

---

## Project Overview

CareWatch-AI is an intelligent healthcare decision support system developed to predict the risk of 30-day hospital readmission using Machine Learning.

The application assists healthcare professionals by identifying high-risk patients and providing explainable AI predictions for improved clinical decision-making.

---

## Features

- Hospital Readmission Prediction
- LightGBM Machine Learning Model
- Explainable AI using SHAP
- Patient Risk Assessment
- Doctor Dashboard
- Patient Dashboard
- Admin Dashboard
- PDF Report Generation
- Multilingual Support
- Interactive Streamlit Web Application

---

## Technologies Used

- Python
- Pandas
- NumPy
- Scikit-learn
- LightGBM
- SHAP
- Streamlit
- Matplotlib
- Seaborn

---

## Dataset

India Hospital Readmission Dataset

Records: 120,000 Hospital Admissions

---

## Best Model

LightGBM

Accuracy: 81.99%

ROC-AUC: 0.7445

Threshold: 0.25
